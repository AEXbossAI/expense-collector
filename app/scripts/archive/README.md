# Разовые скрипты

Миграции конкретного дня, отработавшие один раз. Хранятся как след
принятых решений, а не как рабочий инструмент.

- `apply_answers.py` — применение ответов директора от 14.09.2026:
  Gamma, Wizz Air, Hertz Cyprus и Bolt на эстонскую компанию,
  Union Mobility не берём в расходы.
- `compare_inbox.py` — разовая сверка собранного с тем, что фин
  директор уже разложила руками. Вопрос «чего нет в папках».
  Заменён реконсилером (`app/tasks/reconciler.py`).
